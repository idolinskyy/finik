ПРРО Checkbox

Фіскалізація через API Checkbox: реалізація, повернення від покупця, анулювання останнього чека зміни.

Налаштування

  1. Відкрийте Картка підприємства.
  2. Увімкніть «ПРРО Checkbox».
  3. Вкажіть License Key каси, логін і PIN касира, тип оплати в чеку (готівка / безготівка).

Продаж і повернення

Після проведення Реалізації або Повернення від покупця Фінік за потреби відкриває зміну в Checkbox і створює фіскальний чек. Для повернення, створеного «На підставі» реалізації з уже виданим чеком, система зв’язує чек повернення з оригінальним.

Анулювання перед розпроведенням

Розпроведення фіскалізованого документа пропонує анулювати чек у Checkbox. Checkbox дозволяє скасувати лише останній чек поточної відкритої зміни зі статусом «видано». Якщо анулювати не можна — оформіть повернення від покупця.

Якщо ПРРО вимкнено або реквізити порожні — проведення працює без чека.
